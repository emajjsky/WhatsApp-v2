### Integrations

#### Integration
- **Description:** 账号接入页调用账号生命周期 API 创建账号、触发配对并刷新状态
- **Frontend Component:** AccountsPage
- **Backend Endpoint:** GET/POST /api/accounts, POST /api/accounts/:accountId/pair, POST /api/accounts/:accountId/logout
- **Data Flow:** 页面加载 -> 请求账号列表 -> 表单提交或按钮操作 -> API 返回 -> 重新加载账号列表 -> 更新选中账号详情

#### Integration
- **Description:** 聊天页调用聊天查询 API 获取聊天列表和消息历史
- **Frontend Component:** ChatsPage
- **Backend Endpoint:** GET /api/chats, GET /api/chats/:chatId/messages
- **Data Flow:** 输入筛选条件 -> 请求聊天列表 -> 选择聊天 -> 请求消息历史 -> 渲染时间线 -> 点击加载更早消息时继续请求 before 光标

#### Integration
- **Description:** 导出页调用导出 API 创建任务并轮询刷新任务状态
- **Frontend Component:** ExportsPage
- **Backend Endpoint:** GET/POST /api/exports, GET /api/exports/:jobId/artifact
- **Data Flow:** 选择聊天和格式 -> 创建导出任务 -> 定时刷新任务列表 -> 状态完成后展示下载链接
