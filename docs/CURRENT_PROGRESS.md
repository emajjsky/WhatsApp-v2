# 当前进度

更新日期：2026-03-31

## 一句话说明

仓库已经进入“本地可跑、主流程可验证、客户界面可直接交付”的阶段，不再是半成品壳子。

## 当前已经完成

### 1. 后端基础

- Go API、配置、日志、HTTP 服务稳定
- PostgreSQL migration 已接好
- Docker 一键启动可用
- SSE 实时推送已接通

### 2. 账号接入

- 创建账号
- 二维码配对 / 配对码配对
- 状态查询
- 退出登录
- 删除账号
- 账号列表接口已做超时回退，避免页面被拖死

### 3. 消息归档

- 实时消息进入 `ingest`
- 聊天和消息入库
- 媒体尝试下载并落地到 `data/media`
- 重连后尽量补拉断线期间遗漏消息

### 4. 导出

- 支持多账号筛选
- 支持多会话勾选
- 支持按日期范围导出
- 每个会话分别创建一个导出任务
- 每个会话分别生成一个文件
- 下载按钮会直接保存到本地
- 支持批量下载

### 5. 客户前端

当前客户只保留：

- 账号接入
- 对话查看
- 导出中心

已调整：

- 首页总览已移除
- Agent 前端入口已隐藏
- 账号卡片固定尺寸并支持内部滚动
- 对话页改成更适合高密度浏览的布局
- 导出页改成按账号分组、多选、固定高度滚动列表
- 实时更新恢复，不再只靠轮询

### 6. 跨平台交付

- Windows：`docker-up.bat` / `docker-down.bat`
- macOS / Linux：`docker-up.sh` / `docker-down.sh`
- `docker-up.ps1` / `docker-down.ps1` 仍被 Windows 启动脚本调用，暂时不能删除

## 当前仍未完成

### 2. 导出 worker

### 3. Agent 客户流程

Agent 后端还在，但客户端入口已隐藏，不属于当前交付重点。
