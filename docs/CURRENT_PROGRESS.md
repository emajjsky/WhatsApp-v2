# 当前进度

更新日期：2026-03-28

## 一句话说明

仓库已经进入“本地能跑、核心流程可验证、客户界面已收窄”的阶段。

## 当前已经完成

### 1. 后端基础

- Go API、配置、日志、HTTP 服务稳定
- PostgreSQL migration 已接好
- Docker 一键启动可用

### 2. 账号接入

- 创建账号
- 二维码配对 / 配对码配对
- 查询状态
- 退出登录
- 删除账号
- 账号列表接口增加超时回退，避免整页卡死

### 3. 消息归档

- 实时消息进入 `ingest`
- 聊天和消息入库
- 媒体尝试下载并保存到 `data/media`

### 4. 断线消息补齐

- 会话层支持自动重连
- 重连成功后，会尽量按聊天补拉一段历史
- 目标是尽量把断线期间漏掉的消息补回来

### 5. 导出

- 支持多账号筛选
- 支持多会话勾选
- 支持按日期范围导出
- 每个会话分别创建一个导出任务
- 每个会话分别生成一个文件
- 下载按钮会直接保存到本地

### 6. 客户前端

当前客户只保留：

- 账号接入
- 对话查看
- 导出中心

已调整：

- 首页总览已移除
- Agent 前端入口已隐藏
- 账号列表固定尺寸卡片 + 内部滚动
- 对话页改成更适合大量会话浏览的布局
- 导出页改成按账号分组勾选会话

## 当前仍未完成

### 1. 离线消息绝对补齐

目前只能做到“尽量补”，还不能承诺所有断线期间消息百分百补回。

### 2. 导出 worker

导出任务仍由 API 进程内异步执行，还没拆成独立 worker。

### 3. Agent 客户流程

Agent 后端还在，但客户前端入口已隐藏，不作为当前交付重点。
