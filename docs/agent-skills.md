# Agent Skill / 话术包管理

更新日期：2026-05-25

## 定位

Skill 在本项目里先按“话术包 / 知识包”理解。

一个 Skill 对应一个可命名、可启停、可绑定到回复智能体的知识目录，结构是：

```text
Skill
├── SKILL.md
├── references/
│   ├── 话术文件 1.md
│   ├── 话术文件 2.txt
│   └── 产品说明.csv
└── assets/
    └── 资料登记
```

当前第一版不执行 `scripts`，只读取 `SKILL.md` 和 `references` 文本内容，避免桌面端安全风险和杀毒误报。

## 后台怎么配置

1. 管理员登录云端后台。
2. 进入 `Skill 管理`。
3. 点击 `新建 Skill`。
4. 填写名称、目录名、说明。
5. 编辑 `SKILL.md`，写清楚这个话术包什么时候使用、回复目标和注意事项。
6. 在 `references / assets` 里新增或上传参考文件。
7. 保存 Skill。
8. 进入 `智能体配置`。
9. 选择 `回复智能体`。
10. 在 `绑定 Skill` 区域勾选需要生效的话术包。
11. 保存智能体。

桌面端用户生成回复建议时，会自动使用云端后台配置好的回复智能体和已绑定 Skill。

## SKILL.md 推荐模板

```markdown
# 入群转化话术

## 何时使用
当客户已经表达兴趣、询问费用、询问进群方式、对操作流程不清楚时使用。

## 回复目标
把客户从普通咨询推进到入群或私域承接，同时保持自然、克制、不过度承诺。

## 使用要求
- 优先结合 references 中的话术和知识。
- 不要承诺收益、保本、稳赚。
- 不要输出内部分析过程。
- 如果客户风险较高，先安抚和解释，再引导下一步。
- 输出 3 个不同策略时，每个策略都要有清晰差异。
```

## references 怎么放

`references` 可以放多个文件。

建议按场景拆分：

```text
references/破冰话术.md
references/费用异议.md
references/入群引导.md
references/操作小白解释.md
references/风险合规禁语.md
```

生成回复时，系统会结合客户当前消息和上下文，从已绑定 Skill 的 references 中挑选相关内容注入给模型。

## 当前边界

- 当前只把 `reference` 类型的文本内容参与回复生成。
- `asset` 先用于资料登记，暂不直接参与模型检索。
- PDF / Word 文件当前不做服务端抽文本，建议先上传或粘贴为 `.md` / `.txt` / `.csv` / `.json`。
- Skill 只绑定到回复智能体，翻译智能体和状态卡智能体不会使用 Skill。
- Skill 配置保存在云端数据库，不放进 Windows 安装包。

## 验收方式

1. 在云端后台新建一个 Skill。
2. 新增至少一个 `references/xxx.md`。
3. 在回复智能体里勾选该 Skill。
4. 桌面端打开任意对话，生成回复建议。
5. 如果客户消息命中 reference 内容，回复建议应明显参考话术包内容。
