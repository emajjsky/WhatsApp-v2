# 本地代理池与账号级出口 IP

## 目标

Electron 客户端在本机保存多个代理，并让每个 WhatsApp 账号单独选择网络出口。云端不保存代理地址、用户名或密码，也不转发 WhatsApp 长连接。

## 使用流程

1. 打开客户端的“IP代理”页面。
2. 手工填写代理名称、协议、地址、端口、账号和密码。
3. 也可以粘贴供应商提供的 `socks://` 完整连接串并点击“解析”。
4. 保存后点击“检测”，确认出口 IP 和连接状态。
5. 回到“登录”页面，选中 WhatsApp 账号。
6. 在“账号出口 IP”下拉框选择代理。
7. 在“连接方式”选择“自动判断（有 Clash 就链式）”“直连代理”或“强制通过 Clash/系统代理链式”。
8. 退出并重新连接该账号，使新的代理绑定生效。

## 如何确认链式是否生效

客户端“IP代理”页面顶部的“本机链路状态”是外层 Clash/Windows 系统代理的实时状态，不是静态文案：

- `检测中`：正在读取系统代理规则并检查代理端口。
- `已检测到`：发现系统代理且端口可达；如果账号绑定了独立代理，连接路径为“Clash/系统代理 → 独立代理”。
- `直连生效`：当前模式明确设置为直连，未使用 Clash/系统代理。
- `不可用`：检测到了代理配置，但地址或端口不可达；自动模式不会采用失效的外层代理。
- `检测失败`：系统代理检测过程发生错误，需要根据页面提示和本机网络状态排查。

状态卡同时显示系统代理规则、外层出口 IP、检测时间和检测地址。页面会自动刷新，也可以点击“立即检测”。系统代理状态通过本机 Electron 接口提供，Clash 账号密码不会上传云端。

状态卡只验证外层 Clash/系统代理。要确认“外层 Clash → 某个账号独立代理”的完整链路，仍需在对应代理行点击“检测”：通过时会记录出口 IP 和检测时间，失败时会显示具体错误。只有这两层都通过，才算该账号的链式路径完成验证。

如果 Clash 只开启了 TUN、没有向 Windows 注册系统代理规则，客户端只能显示“未发现 Windows 规则”，不能凭 `resolveProxy` 接口确认 TUN 当前节点；这种情况下以对应代理行的真实链路检测和账号实际连接结果为准。

“自动判断”会实时读取本机 Windows 系统代理/Clash：有可用入口时使用“本机 Clash/系统代理 → 账号独立代理”，没有入口时直接连接账号代理，适合境外网络。“强制链式”在没有可用系统代理时会明确报错，不会泄漏到本机 IP。未选择代理时，账号使用本机网络或系统代理。

代理不可用、禁用或过期时，客户端不会自动回退到本机 IP。`auto` 模式只有在本机 Clash/系统代理入口不可用时，才会改为直连账号自己的独立代理；`system`（强制链式）检测不到外层代理会直接失败，不会泄漏到本机 IP。Clash 节点切换后，客户端会检测到系统代理入口变化并重建已连接账号的长连接，账号设备凭据不会被删除，也不需要重新扫码。

保存代理绑定后，客户端会自动重建该账号的网络连接；已登录设备不会被删除，也不需要重新扫码。若账号正在扫码或尚未建立设备连接，绑定会在下一次连接时生效。

## 本地安全

- 代理池保存在 Electron 本地 PostgreSQL 数据库。
- 代理池表和账号绑定表随桌面端本地数据库迁移创建；云端部署不会保存这些本地代理凭据。
- 密码使用本机生成的 AES-256-GCM 密钥加密。
- API 列表只返回代理元数据和 `has_credentials`，不会返回密码。
- 日志、云端鉴权接口和导出数据不包含代理密码。
- 代理凭据不要粘贴到聊天、截图或公开工单中。

## LoongProxy 测试串

供应商格式可能是：

```text
socks://Base64(username:password@host:port)
```

页面会解码并转换为客户端使用的：

```text
socks5://username:password@host:port
```

客户端底层使用统一的代理拨号器：直连时使用 `whatsmeow.Client.SetProxyAddress`；链式时使用“外层 Clash/系统代理 → 内层账号代理”的双层拨号器，版本检查、二维码、WebSocket、媒体上传下载都使用同一路径。IP 代理页的“检测”会分别检查出口 IP 和 WhatsApp Web 可达性；部分代理商会拦截 `api.ipify.org`，这不等于 WhatsApp 不可用，界面会保留“出口 IP 未检测”而不再误报代理失败。

## 一号一 IP 的必要条件

Clash 是外层通道，不会凭空生成多个出口 IP。要让 10 个账号拥有 10 个不同出口，仍然需要保存并绑定 10 个不同的独立代理。10 个账号全部只走同一个 Clash 节点，最终仍然是同一个公网出口，不能达到一号一 IP。

## 验收标准

- 两个 WhatsApp 账号可以同时连接。
- 两个账号分别绑定不同代理时，出口 IP 不同。
- 客户端重启后绑定关系不丢失。
- 代理断开时对应账号失败，其他账号不受影响。
- 代理失败时不出现静默直连。
- 未绑定代理的账号保持本机直连。
- 国内测试电脑可通过 Clash 链式连接账号代理，境外电脑可自动切换为代理直连。

## 当前测试记录

本机可以先选择“本机 IP（直连）”继续测试登录、对话和智能体功能。代理池的连接检测必须在供应商允许的网络环境中进行；如果供应商要求境外网络，中国大陆本地直连可能被拒绝。国外客户可以直接在客户端填写自己的固定代理并检测出口 IP。
